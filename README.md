# Car Rental System

Welcome to my **Car Rental System** created in C# where Customers and Admins are able to use this system. The Customers are able to view any available cars, rent a car, make the payment, return the rented car as well as view their own rentals. The user also has the option to Logout. 

The Admins are able to add cars to the system, view the cars added edit the cars added, remove the car added and also has the option to Logout. 

The information/details of the Users, Cars, Payment and Rental details are stored in the Database which is where I made use of Sql Management Studio.

My goal is to use this C# created Car Rental System as a blueprint to create Car Rental System as a Front-End Application using React.
