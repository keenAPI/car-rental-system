# Car Rental System

Welcome to my Car Rental System. I have created this Car Rental Service in C# and this time I will be adding a database by using SQL Management studio to store the User's information after they registered for example Name, Email, Password and Role. I managed to create two roles which is the Customer and Admin. The Customer is able to see the Brand name of the car along side the Model, Year and the Price per day. The Admin is able to Add a car, View, Edit and delete cars.
